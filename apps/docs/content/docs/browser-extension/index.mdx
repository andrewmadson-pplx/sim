title: Sim browser extension
description: Ask Sim about the page you’re reading, open team shortcuts, or use Sim Home as your Chrome new tab.
---

[Install Sim for Chrome](https://chromewebstore.google.com/detail/sim/oanlcahddodnjpdoopcpjlcageejjpmg) to ask questions about a page without leaving it. Open Chrome’s **Extensions** menu and pin **Sim** to keep it one click away. Installing the chat extension leaves your new tab page unchanged.

## Ask about a page

1. Open a web page and click **Sim** in the Chrome toolbar. Sign in to Sim if prompted.
2. In the side panel, select the attachment chip to review the captured text, or use its **×** to remove it. To attach the page again after it changes, use the globe next to the message field.
3. Ask a question and send it. For example, on a release notes page, ask “Which changes affect my team?”

To ask about a passage, select the text on the page, right-click, and choose **Ask Sim about selection**. You can attach up to three snapshots to compare pages. A snapshot stays as it was when you captured it. Chrome settings pages, other extensions, and pages without readable text can’t be attached.

For faster access, press **Command + Shift + S** on macOS or **Alt + Shift + S** on Windows and Linux. If the shortcut is already assigned, choose another in Chrome’s **Extensions → Keyboard shortcuts**.

## Use Sim as your new tab

Sim New Tab is a separate, optional Chrome extension. Its store listing is not public yet. When it becomes available, install the companion and keep the change when Chrome asks. Open a new tab to see your Sim Home using your existing account and organization access. The address bar still uses your usual search engine.

To turn it off, select **Restore previous new tab** at the bottom of the page and confirm removal. Or open **Extensions → Manage extensions** and turn off **Sim New Tab** if you want to keep it installed. On your next new tab, Chrome uses its default page or the previous enabled new-tab extension. Sim Chat stays installed. If your organization manages this setting, its browser policy takes precedence.

## Roll out to a team

Share the chat extension’s install link with your team. In managed Chrome, an admin can [allow the extension for an organizational unit](https://support.google.com/chrome/a/answer/6306504) so people can install it themselves. Allow Sim New Tab separately if people want it; force-installing it prevents them from turning it off themselves.

If your organization has [Sim Links](/search/sim-links), try a memorable shortcut like `sim/handbook`. Type `sim`, press **Space**, and enter part of a link name for suggestions. Teams that already use an internal host named `sim` should keep that hostname conflict in mind: the chat extension routes those navigations to Sim.

## Page access and privacy

Sim reads a page or selection only when you ask. For repeat use on one site, choose **+ → Site access** to grant or revoke that site’s permission. Granting access doesn't start background capture. The page text goes to the hosted composer when attached and becomes part of the conversation when you send it.

Sim New Tab loads Sim Home and does not read your other tabs or browsing history. See [Sim’s browser extension privacy disclosure](https://www.sim.ai/privacy#browser-extension).
